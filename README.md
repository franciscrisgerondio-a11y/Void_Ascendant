# 🌌 VOID ASCENDANT

**Void Ascendant** is a futuristic **browser-based RPG interface prototype** built with **HTML, CSS, and JavaScript**.
The project features a highly stylized **cyber-mystical UI** where players interact with a fictional cultivation / ascension system inside a dark sci-fi universe.

The design blends **fantasy cultivation themes** with **cyberpunk interface aesthetics**, creating a game-like dashboard that tracks player progression, realms, and stats.

---

# ✨ Features

## 🧬 Ascension / Cultivation System

The interface revolves around the concept of **ascending through realms** and strengthening your character.

The UI displays:

* 🌌 Current **Realm**
* 📊 Player **statistics**
* ⚡ Progress toward the next **ascension stage**
* 🧠 Various power attributes

This gives the feeling of a **cultivation RPG progression system**.

---

# 🖥 Interface Layout

The application uses a **three-panel game dashboard**:

### 🧭 Left Panel

Contains player information and progression elements such as:

* Character statistics
* System status
* Power indicators
* Game-related panels

---

### 🎮 Center Panel

Main gameplay display.

Used for:

* Core interaction area
* System messages
* Player actions
* Event displays

This is the **primary gameplay interface**.

---

### 🛰 Right Panel

Contains supporting gameplay information such as:

* Additional stats
* System monitoring panels
* Supplemental information

---

# 🎨 UI Design

Void Ascendant features a **highly stylized futuristic interface**.

### Visual Elements

* 🌌 Dark **void-themed color palette**
* ⚡ **Neon cyan and violet highlights**
* 🔷 Glassmorphism-style panels
* ✨ Glow effects and animated gradients
* 🌠 Particle background animation
* 🖥 Terminal-style fonts

### Fonts Used

* **Cinzel** – fantasy / epic headings
* **Rajdhani** – modern UI text
* **Share Tech Mono** – terminal style system data

The design creates the feeling of a **mystical AI system controlling a cosmic power interface**.
